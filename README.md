# HijaukanKode

HijaukanKode adalah website edukasi lingkungan dan checklist aksi harian ramah lingkungan untuk semua kalangan masyarakat. Website ini dibuat dengan React, Vite, Tailwind CSS, lucide-react, dan localStorage.

## Menjalankan Project

```bash
npm install
npm run dev
npm run build
```

## Deploy ke Vercel

1. Push project ini ke GitHub.
2. Buka Vercel dan pilih `Add New Project`.
3. Import repository HijaukanKode.
4. Gunakan konfigurasi default Vite:
   - Build Command: `npm run build`
   - Output Directory: `dist`
5. Klik `Deploy`.
